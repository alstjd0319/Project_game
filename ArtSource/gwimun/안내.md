## 2. 콘셉트 요약 (팀 결정)

- **이야기**: 열린 귀문(저승으로 통하는 문) 안으로 들어가 가장 깊은 곳의 문을 닫는다. 스테이지는 전부 귀문 **안**(이승을 뒤틀어 흉내 낸 세계). 귀문 밖은 거점 사당뿐. 죽으면 귀문 밖으로 튕겨 나오고 길이 매번 바뀐다.
- **주인공**: 떠돌이 도사 퇴마사 — 갓 · 옥색 도포 · 방울 지팡이. 무기 2개를 자유롭게: **봉(근접)** / **부적(원거리)**.
- **전투**: 방어는 **패링뿐**. 패링하면 **요기**가 차고 요기로 스킬. 스킬 트리(사당).
- **성장 · 재화**
  - 돈(엽전): 이번 판 상점용
  - 영혼석(보라 결정): 판이 끝나도 남음, 스킬 트리용
  - 경험치(청록 혼불): **영구 레벨업**
  - **업경**(사당의 거울): 레벨업 포인트를 다섯 갈래에 나눠 찍음(던그리드 어빌리티 방식, 5·10·20포인트마다 추가 효과)
    - 청룡 공격 · 백호 속도·치명 · 기린(가운데) 재화·행운 · 주작 요기·스킬 · 현무 방어·체력
- **방 7종**(포탈로 선택): 일반 · 엘리트 · 상점(우렁각시) · 보상 · 휴식 · 이벤트 · 보스.
- **등장인물**
  - 우리 편: 스승 만신, 상점 주인 우렁각시, 수호신(사신수 + 기린 — 전투 동작 없음)
  - 일반 요괴: 창귀 · 도깨비불 · 두억시니 · 장산범 · 어둑시니 · 달걀귀신 · 도깨비 · 처녀귀신 · 구미호 · 물귀신
  - 엘리트: 저승사자
  - 중간 보스·엘리트 겸용: 사흉수 4마리
  - 보스: 3구간 불가살이(2페이즈), **최종 염라대왕**(2페이즈)
- **그림 규칙**: 컬러 도트. **빨강은 적 공격 경고에만**(예외: 주작 UI). 한국 것만.

## 3. 게임 규격

- 화면 **1920×1080 그대로**, **1유닛 = 90px** (Unity Pixels Per Unit = 90, Filter = Point, 압축 없음).
  - 지금 게임 코드는 옛 규격(960×540 ×2, 45px/유닛)이라 새 그림을 넣을 때 바꿔야 한다.
- 크기
  - 주인공 키 약 128px(≈1.4유닛, 지금 판정 상자 0.8×1.4와 맞음)
  - 요괴: 창귀 140 · 두억시니 192 · 도깨비 176 · 저승사자 144 · 그 밖의 요괴 약 128
  - 보스: 사흉수 288 · 불가살이 320/480
  - 염라: 몸 900(화면 뒤 배경처럼 큼) · 손 약 200
- 판정은 그림과 별개(판정 상자는 지금 게임 그대로, 그림은 자식 오브젝트로 겹침).

### 시트 읽는 법

- `미리보기/<이름>_<시트>_strip.png` = 가로 한 줄 스트립. 왼쪽부터 칸 폭(cellW)씩 잘라 frames개.
- 모든 그림은 **오른쪽을 본다**(왼쪽은 flipX).
- 기준점(pivot)은 칸 왼쪽 위에서 잰 px. `ground` = 발끝(땅), `center` = 무게중심(떠 있는 것·이펙트). Unity 피벗은 0~1, 아래가 0.
- 프레임 위치는 시트 안에서 이미 맞춰져 있다.

## 4. 이펙트 (P8 퇴마사 · `fxhero_manifest.json`)

- 파일 이름 규칙
  - `_start` / `_loop` / `_end`: 긴 이펙트. 시작 → 반복(원하는 시간만큼) → 끝.
  - `_plus`: 강화판. 같은 모양에 더 크고 밝고, 요기의 보라·흰빛이 섞임.
  - `_a` / `_b`: AI가 한 장에 다 못 그려 두 장으로 나눈 것 → **a 다음 b**로 이어 재생.
    - 일부(방벽·결계 벽·분신 사라짐·최종 봉인)는 b 첫 프레임이 a와 살짝 겹치거나 되돌아간다. 프레임 몇 개를 빼고 쓰면 자연스럽다.
- 배경이 검정이던 이펙트(빛·불·번개)는 **더하기 합성(Additive)**으로 그리면 원래 느낌. 나머지(먼지·흙·분신·현무)는 일반 알파.
- 크기는 원본의 1/2(궁극기 1/1.4, 먼지 1/3) — 크기는 게임에서 자유롭게 키워도 된다.
- 목록
  - 기본: 봉 3연타, 모아치기, 공중 내려찍기, 대시 잔상, 먼지 3종, 부적 모으기·적중·모아 던지기
  - 패링·요기: 완벽 패링, 패링 충격파, 큰 반격 베기, 요기 흡수, 요기 가득 오라, 요기 폭발
  - 봉 스킬: 회오리, 땅 충격파, 연속 찌르기, 용오름, 낙뢰, 바람 방벽 (각각 강화판)
  - 부적 스킬: 부적 폭풍, 봉인진, 부적 사슬, 화염부, 번개부, 분신술, 결계 벽, 호신부
  - 궁극기: 청룡·백호·주작·현무·기린 소환, 부적 만다라 최종 봉인

## 5. 배경

`미리보기/bg/<장소>/`에 가공 결과(배경 투명 PNG). 원본은 1536×1024 → 세로 1080에 맞춰 1.055배로 쓰면 1080p 화면 높이와 같다.

- 장소: shrine 사당 · zone1~3 · boss 불가살이방 · yeomra 명부전 · shop 상점 · rest 휴식 · reward 보상
- `far` 먼 배경 / `mid` 중간 / `near` 가까운(있는 곳만): 좌우로 **반복**할 수 있게 이음새 처리 완료
  - 사당·1구간 near는 땅 높이 건물이 있어 주인공 **뒤**에, 2·3구간 near는 가장자리 풀뿐이라 **앞**(전경)에 추천
- `props_NN` 소품, `tiles_NN`(옛 P3 타일 — 지형은 아래 6장의 새 타일 세트를 쓸 것)
- 명부전: 가운데 위가 비어 있음 → 염라 상반신이 그 자리에 솟음(`yeomra_p1_screen.png` 참고)
- 오브젝트: `bg/objects/`(수호신 석상 5, 방별 포탈 틀 7), `bg/ui/`(UI 조각 — HUD·아이콘·대화창·스킬 트리·업경 화면·방 표식·재화 아이콘), `bg/mentor_portraits/`(만신 초상)
- 포탈 소용돌이: P1의 `fx_gate_portal`을 방마다 색만 바꿔 쓰는 계획(색 바꾼 판은 아직 안 만듦)

## 6. 지형 · 타일맵 (P7) — `미리보기/tiles/<구간>/`

구간: shrine · zone1 · zone2 · zone3 · boss · yeomra. 구간마다 같은 구성.

- **타일 한 칸 = 90px = 1유닛.** 그림은 칸보다 사방 30px 큼(150×150, 풀·매달린 뿌리가 칸 밖으로 나옴). **피벗 가운데 + PPU 90**이면 칸에 딱 맞음.
- `ground_NN` 16종: NN = 위·아래·좌·우 이웃이 땅인지 비트(N=1, E=2, S=4, W=8). 모서리·안쪽 모서리가 이 규칙으로 자동으로 맞음.
- `ground_15_var0~3`: 속이 꽉 찬 타일의 무늬 변형 → 섞어 쓰면 반복이 덜 보임(Rule Tile의 랜덤 출력).
- `thin_left/mid/right/single`: 아래에서 뚫고 올라가는 얇은 발판(판정 높이 약 30px).
- `slope45_*`, `slope22_*`: 경사로(쓸지 말지는 선택).
- `backwall.png`(270px 반복 뒷벽, 판정 없음), `pit.png`(구멍 바닥 풍경, 가로 반복).
- `<구간>_tiles.json`: 모든 타일의 이름·규칙·아틀라스 위치. `<구간>_atlas.png`: 한 장으로 모은 것.
- **Unity Rule Tile**(붓질하면 모서리 자동)을 쓰려면 "2D Tilemap Extras" 패키지가 필요(지금 프로젝트엔 없음, 설치는 선택).
- 발판·함정·꾸미기 조각: `미리보기/bg/terrain_<구간>/`(원본 크기 — 게임에선 약 1/3.5로 줄이면 타일과 맞음).
- 공용: `미리보기/bg/terrain_common/`(부서지는 벽, 사다리·덩굴·사슬, 출입문 3종, 움직이는 발판 3종), `terrainobj_*`(부서지는 애니메이션, 체크포인트 석등).

## 7. 알려진 문제 · 아직 안 정한 것 (임의로 확정하지 말 것)

- 보스 크기: 불가살이 2페이즈·사흉수가 큼. 보스방 크기에 맞춰 줄일 수 있음(가공 설정 숫자 하나).
- 불가살이·염라 피격 시트는 1·2페이즈 프레임이 섞여 1페이즈 크기로만 맞춤.
- 구미호 꼬리 아홉 개가 하나하나 구분되진 않음(부채꼴 덩어리).
- 2구간 청사초롱·엽전 꾸러미 끈이 빨간색(경고색 규칙과 겹침).
- UI 조각은 대충 자른 상태(점선이 점으로 갈라짐 등).
- 지형 속 무늬 반복이 희미하게 보임. 1구간 중간 배경에 분홍빛 점이 몇 군데 남음.
- 원본이 작게 그려진 요괴·보스는 주인공보다 픽셀이 살짝 굵다.
- 효과음·음악 없음. P9(적·보스 이펙트), P10(버프·상태)은 다음 묶음.

## 8. 원본을 다시 가공하려면

- `원본/` = AI(Codex)가 뽑은 그대로. 마젠타(#FF00FF)·초록(#00FF00)·검정 배경은 지우기용 색.
- 도구 사본은 `도구/`(저장소 기준 `Tools/sprites/`, `Tools/tiles/`, `image_request.md`). 저장소 폴더 구조에서 실행해야 한다.
  - `process_sheets.ps1`: 캐릭터·이펙트 시트 → 스트립 + 미리보기 + manifest
  - `process_bg.ps1`: 배경 이음새·소품/타일/UI 자르기
  - `autotile.py`: 지형 재료 → 타일 세트 (Python 3 + numpy, scipy, pillow)
